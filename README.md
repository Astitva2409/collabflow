# CollabFlow

CollabFlow is a full-stack project collaboration and task management platform.

## Tech Stack

### Backend
- Java 21 / 22
- Spring Boot
- Spring Security
- PostgreSQL
- Flyway

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

## Features (Planned)

- Authentication (JWT)
- Workspace management
- Project management
- Kanban board
- Task management
- Comments
- Notifications
